# Container ids reported by players, for vehicles not installed on this machine.
#
# generate_container_ids.py can only see vehicle scripts that are actually here, so a
# car nobody in the build environment owns is invisible to it. The mod's own audit
# prints the exact container type when it meets one, which is where these come from:
# they are the game's own strings, copied out of a report, not guesses.
#
# A second source, marked where used: the loot tables in Specific Loot (KI5). Those key
# each container by the part id the game looks the loot up under, so they only work if
# the id is the real one. Less direct than a report, but an id that turned out wrong
# would only register a hidden item nothing uses.
#
# One id per line. Blank lines and # comments ignored. Delete an entry once the vehicle
# is installed locally, since the scan will then find it on its own and a duplicate here
# is just something else to keep current.
